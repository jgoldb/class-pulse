## Decisions

- **Edit route lives under `/api/classroom`.** The spec offered `PATCH /api/sections/:id` "following
  the repository's conventions"; the teacher's own sections are already under `/api/classroom`.
- **Period stays a schedule tag.** Class Pulse copies it onto each session as a context tag the
  pattern engine reads, so it is validated against the schedule vocabulary (`period_1`–`period_8`,
  morning, afternoon) rather than accepting free text.
- **Removing a student removes the enrollment only.** Hard-deleting a learner with history would
  break provenance; the learner-erasure path (administrator, docs/04) remains the way to erase.
- **Ending a session is a status, not a lock.** Review, confirmation, correction and drafting all
  happen after the bell, so the API keeps accepting them; the UI asks the teacher to resume before
  new capture.
- **Teacher reassignment is not on the teacher surface.** Edit Class shows who teaches the class
  and says that an administrator changes it.
